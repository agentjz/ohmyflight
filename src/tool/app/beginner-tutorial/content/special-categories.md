# 特殊类别

## 副驾驶特殊类别

A1、A2、B、C、D构成当前手册明确给出完整条件的副驾驶主线。技术管理手册在运行搭配和技术等级清单中还出现E类副驾驶，但本次两本手册读取范围没有给出E类副驾驶完整的取得条件。E类不放入A1至D主线，页面标记为“条件未完整给出”。

## 机长特殊类别

B、C、D是手册中具有明确升级或聘任关系的机长类别。Z类是巡航机长，不属于可以独立履行机长职责的机长；它是运行状态，不应被画成B至D之间的普通升级节点。

R类是特定历史条件下形成的代班机长类别。手册规定R类不得晋升技术等级，因此它是特殊分支，不是B至D主线的一步。

S类是特定年龄、机长经历和公司评估条件下形成的资深机长类别。R类和Z类机长不得直接聘任S类机长。S类同样作为特殊分支维护。

## 教员

运输航空飞行教员分为航线飞行教员、型别教员和本场飞行教员。训练大纲中本场飞行教员章节有意留空，因此页面不为本场飞行教员编造一套课程。

航线飞行教员分为L1和L2。L2拥有L1权限，并对A1副驾驶及E类副驾驶、巡航机长的座位和操纵权限产生不同影响。型别教员拥有L2航线飞行教员教学权限。型别教员本身按B1、B2、B3、B4分级，级别决定可承担的教学范围，必须结合聘任后才能行使权利。

## 考试员

考试员是独立于教员的检查分支，包括公司检查员和飞行检查委任代表。公司检查员按I、II、III类以及A、B子类管理；委任代表的推荐、批准、任期和监察按其局方管理要求执行。考试员不能因为完成教员训练就自动取得。
