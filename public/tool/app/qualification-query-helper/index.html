技术等级运行资格查询助手（乞丐版）

本地 Playwright 工作台，逐人查询技术等级和运行资格并即时保存

运行方式

下载独立应用后，在应用目录运行 python start.py。在本地工作台粘贴当前登录 Cookie，导入 Excel 或人员文本，先进入资料管理页面，再人工点击开始查询。

查询完成后浏览器保持打开，可继续准备下一批；只有点击停止或关闭本地服务才关闭浏览器。
