飞行经历查询（乞丐版）

本地页面驱动飞行门户查询，按页面表头保存完整结果

运行方式

下载独立应用后，在应用目录运行 python start.py。工作台提供四个范围复选项、Excel 和粘贴两种输入，以及进入页面、数据健康检查、开始查询和终止等分步操作；查询结果会逐人显示并即时保存。

依赖

使用前请确保已安装以下依赖：

  • Python 3.10+
  • playwright（浏览器自动化）
  • openpyxl（Excel处理）

安装命令：

pip install -r requirements.txt
playwright install chromium
