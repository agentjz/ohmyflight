锁班乞丐

本地工作台驱动飞行门户非生产任务串行录入

运行方式

下载独立应用后，在应用目录运行 python startsmartapp.py 或 python startapp.py。两个入口分别启动固定模式的本机工作台，提供 Excel/粘贴输入、白名单、统一备注、进入录入页面、数据健康检查、开始录入和终止等分步操作。

智能串行工作台保留健康疗养与飞行员公休额度路由及可选冲突回退；原始串行工作台按输入类型和日期原样录入。每批完成后浏览器保持打开，可继续准备下一批。
