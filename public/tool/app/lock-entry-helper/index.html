锁班皇帝

自动化填写飞行门户非生产任务录入表单

工具介绍

这是一个 Python 脚本工具，用于自动化填写飞行门户的非生产任务录入表单，提供原始串行和智能串行两种流程。

两个 APP 均支持白名单、可选统一备注和结果归档；智能路由助手支持全部锁班类型，其中健康疗养与飞行员公休会按额度自动分配，并可处理唯一旧锁班造成的日期冲突。

当前版本说明：
  • startsmartapp.py - 智能串行助手：普通类型原样录入；健康疗养与飞行员公休按额度拆分；日期冲突时可解锁唯一旧记录并重提一次
  • startapp.py - 原始串行助手：稳定单页流程，支持批量、手动、Excel 导入三种模式，实时写入结果 Excel
  • 启动时可选填写统一备注，输入 OK 确认后复用于本次全部记录
  • 智能助手会尝试回退唯一旧锁班；无法回退或重提仍失败时记录原因并继续下一条
