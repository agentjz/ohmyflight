锁班皇帝（新）

使用已登录会话，通过本地 HTTP 工作台串行录入非生产任务

运行方式

下载独立应用后，在应用目录运行 python startsmartapp.py 或 python startapp.py。从已登录飞行门户的浏览器 Network 面板复制请求为 cURL，粘贴到本地工作台验证后即可继续使用原有 Excel 或粘贴数据。

智能入口保留健康疗养与飞行员公休额度互换及可选冲突回退；原始入口按每行类型原样录入。批次结束后登录 Session 保留，可直接更换下一份数据。
