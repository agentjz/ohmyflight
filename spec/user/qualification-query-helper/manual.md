# 技术等级运行资格查询助手（乞丐版）用户手册

## 准备

1. 下载并解压独立应用。
2. 运行 `pip install -r requirements.txt` 和 `playwright install chromium`。
3. 运行 `python start.py`，浏览器会打开本地工作台。
4. 在已经登录 IEB 的浏览器中复制完整 Cookie Header 或请求的 Copy as cURL 内容。

Cookie 只用于当前本地浏览器会话。页面不会保存或显示 Cookie；浏览器关闭后需重新粘贴。

## 分步查询

1. 粘贴 Cookie。
2. 选择 Excel 或粘贴输入。Excel 需要 `员工号`、`工号` 或 `员工编号` 表头，`姓名`可选；粘贴时每行写一个六位员工号和可选姓名。
3. 点击“导入登录态并进入查询页面”。可见 Chromium 会打开并进入资料管理，工作台日志依次显示打开浏览器、验证登录态和进入各级菜单。
4. 状态变为“页面已就绪”后，可点击“数据健康检查”查看有效和无效人数。健康检查不是开始查询的前置确认。
5. 点击“开始查询”。页面会逐人显示技术等级条数、运行资格条数和状态，结果 Excel 每人即时保存。
6. 完成后下载结果 Excel 和文本报告。浏览器继续保持打开，可更换输入后点击“准备下一批”。
7. 不再查询时点击“停止并关闭浏览器”。

## 结果

- `处理报告`：先看每个人是否成功、页面姓名是否一致以及两类记录数量。
- `技术资料明细`：查看具体技术等级和运行资格。
- `汇总`：查看有效人数、成功、失败、输入错误和中断状态。
- 文本报告：不打开 Excel 时快速查看本轮汇总。

重复员工号、无效员工号和单人查询失败都会写入结果，不会静默丢弃。门户结构变化或登录态失效时，以页面日志和处理报告为准，不要把空表当成没有资质。
