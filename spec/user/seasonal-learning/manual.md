# 换季学习

## 导入并生成初版

1. 打开“换季学习”。
2. 选择包含 `换季实际`、`换季总名单`、`所有人` 的 Excel 工作簿。
3. 先查看 Excel 健康检查中的严重、警告和提示，以及带身份和未标身份人员。
4. 如果 `换季实际` 为空，导入后所有人员先显示为待分配。
5. 设置期数和每期日期，期数默认 6 期。
6. 点击“均衡负载”生成一次均衡初版。

如果 `换季实际` 已有期数，页面优先恢复实际期数和日期，不显示“均衡负载”。初版生成或实际安排恢复后，期数锁定，页面不会在后续操作中自动重新排人。

## 填写日期

在顶部“每期日期”区域填写各期培训日期。日期修改后，卡片、图表和导出结果同步更新。

总名单中已有的个人日期不会固定初版期次。

## 查看 Excel 健康检查

健康检查会显示两张名单人数、重复员工号、实际名单漏掉或多出的人员、未填写期数人员和身份不一致人员。实际名单只有表头时会显示尚未生成安排，不会把全员报成漏排。

“带身份人员”按身份文本分组显示姓名，“未标身份人员”可以展开查看。身份内容不限制为固定类型；以后新增任意身份文字也会自动使用稳定的浅色标记，同一身份始终显示相同颜色。

## 查看均衡

图表显示每期带队机长、机长、副驾驶的堆叠人数和总人数。

期次卡片中的每个人都会同时显示姓名、三类角色和总名单中的技术信息，例如“副驾驶”和“777:A一类副驾驶”，便于直接核对技术等级。总名单身份非空时，姓名旁同时显示浅色身份标记；身份为空时不显示标记。

首次点击“均衡负载”会真正生成初版；此后按钮切换为“均衡检查”。点击“均衡检查”只检查以下四项，不会改动任何人员：

- 总人数
- 带队机长
- 机长
- 副驾驶

需要检查的期次会在均衡结果和期次卡片中标出。存在待分配人员时，整体均衡检查不通过。

## 移动人员

1. 在期次卡片或待分配区勾选一人或多人。
2. 点击当前期次卡片或待分配区右上角的“移动所选”。
3. 在弹窗中选择目标期次。
4. 点击“确认移动”。

单人和批量移动使用同一操作。移动后页面只更新人数、均衡状态和调整记录，不重新安排其他人员。
需要调整两批人员的期次时，分别勾选两批人员并执行两次移动；每次移动都会保留调整记录。页面不提供撤销操作。

## 更新总名单

在当前页面再次导入更新后的工作簿：

- 相同员工号保留当前期次。
- 新增人员进入“待分配”。
- 删除人员显示在“名单变更”。
- 页面只重新检查均衡，不自动处理新增或删除造成的差异。

如果重新导入的文件在 `换季实际` 中已有安排，则以该文件的实际安排为准。

## 导出

点击“导出 Excel”生成 `<原文件名>_换季实际.xlsx`。

导出结果写入 `换季实际`，保留“身份”列并增加“调整说明”列。人工调整过的人员整行使用浅红色底色、黑色文字。名单按期数、日期和原始序号排序；待分配人员位于末尾，期数和日期为空。

`换季总名单` 和 `所有人` 不由工具修改。原始文件不会被覆盖。
