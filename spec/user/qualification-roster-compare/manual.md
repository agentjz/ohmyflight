# 运行资质比对用户手册

打开工具后分别上传人员信息 Excel 和飞行门户运行资质人员名册 Excel。系统按表头自动识别工作表和字段；两个文件均读取成功后点击“开始比对”。

结果区先给出总体数量，再按资质查看双方人数和人员明细。默认只显示差异，资质下拉可选择“显示全部”跨资质查看，也可选择具体资质；状态下拉可切换“全部”“双方一致”“仅飞行门户”或“仅人员信息”。明细表会逐行标出资质类别、员工号、两侧姓名和提示。数据问题区会列出缺少员工号、非法角色、重复关系、姓名不一致等提示。

点击“导出 Excel”可下载包含资质汇总、差异明细和数据问题的复核文件。工具只在浏览器本地处理，不修改上传的原始文件。
