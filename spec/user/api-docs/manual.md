# API 文档用户手册

从工具首页顶栏打开“API 文档”。该入口不占用工具卡片；页面左侧统一管理 Cookie，展开“飞行门户”后可选择飞行经历查询、飞行人员锁班和飞行人员信息查询。后者再按基础信息、技术等级、运行资格、训练检查记录分组展示五个真实请求。

## Cookie

在飞行门户中登录后，从浏览器 Network 复制完整 Cookie Header 或 Copy as cURL，粘贴到 Cookie 管理区并验证。验证成功后页面显示可复制的规范化 Cookie Header。刷新、重新打开或点击清除后不会保留旧 Cookie；保活状态与当前会话一致。

## 调试请求

选择接口，填写技术上必要的员工号、日期或锁班参数，点击发送请求。页面同时显示 HTTP 方法、最终 URL、状态码、响应 Headers、用户友好的表格/摘要以及原始 JSON 或 HTML。锁班接口仍是写操作，接口文档不会替你批量提交、自动通过、解锁或处理冲突；批量业务使用独立工作台。

飞行人员信息查询的培训记录接口在文档中按页单次调用；要读取全部分页，请使用“飞行人员信息查询（皇帝版）”工作台。

## Markdown 导出

点击“导出 Markdown”得到一个单文件文档，内容包括认证说明、三个模块、请求方法和地址、参数、响应契约、内部请求链路、技术说明及原始目录 JSON。导出不需要启动本地后端，也不包含粘贴的 Cookie、真实响应或人员数据，适合人类阅读和文本模型分析。
