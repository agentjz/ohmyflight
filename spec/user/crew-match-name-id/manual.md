# 姓名匹配员工号用户手册

## 解决什么问题

姓名匹配员工号把通知、聊天记录或其他文本中的花名册姓名识别出来，快速得到员工号、姓名、分部、技术信息和技术等级。匹配后可以自由增加业务列，再导出适合整理或直接分享的 Excel 和图片。

## 怎样操作

1. 打开工具，等待默认花名册加载；如加载失败或需要使用新名单，点击重新选择文件。
2. 手动花名册第一行必须包含 `员工号`、`姓名`、`分部`，可选 `技术信息`。
3. 粘贴待识别文本，点击查询匹配。
4. 按员工号、姓名、分部、技术信息、技术等级顺序核对结果，重点确认同名人员。
5. 需要补充申请、备注等业务信息时点击`新增列`，直接修改列头并填写各行内容。一次粘贴多行文本时，内容会从当前单元格开始向下填入。
6. 不需要的自定义列可点击列头右侧删除按钮；自定义列不会修改花名册。
7. 需要复制名单时使用`复制员工号列`或`复制姓名列`；只需要部分人员时先勾选对应行。有勾选时复制、Excel 和图片只处理勾选人员，没有勾选时处理全部结果。
8. 在`图片标题`输入框填写图片顶部文字；它独立于自定义列头，留空时使用`人员名单`。
9. 技术等级默认不导出；需要时先勾选`导出技术等级`，该设置同时作用于 Excel 和图片。
10. 点击`导出Excel`得到带浅色表头、轻边框、居中换行和合适列宽的表格；点击`导出图片`得到只含标题和浅色名单表格的 PNG。

## 操作注意事项

- 工具按花名册完整姓名是否出现在文本中匹配，不做模糊搜索或别名识别。
- 同名人员可能同时进入结果，必须结合员工号、分部人工确认。
- 技术等级从技术信息文本中提取，无法识别时留空，不代表没有技术等级。
- 页面只提供员工号和姓名的单列复制，不提供其他字段的复制按钮。
- 花名册缺少必需表头会停止读取，不会猜固定列。
- 自定义列的列头和每一行内容均为自由文本，Excel 和图片按当前内容原样导出。
- 图片顶部文字只使用独立的`图片标题`输入值，不会自动借用自定义列头；图片不显示标题分割线。
- 点击清空输入会同时清除当前匹配结果、选择状态和自定义列。
- 文件只在浏览器本地解析。
