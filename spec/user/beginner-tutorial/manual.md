# 菜鸟教程用户手册

菜鸟教程面向南货航新员工，用来查询副驾驶技术等级、机长技术等级、教员与考试员、运行资质以及重新获得资格的办理条件和结果。

从工具首页进入后，左侧选择业务模块。模块由现行手册的业务对象组织，当前包括：

- 副驾驶技术等级：查看新雇员、副驾驶转机型、A1→A2→B→C→D 主线和特殊类别。
- 机长技术等级：查看机长转机型、B→C→D 主线和 Z/R/S 特殊类别。
- 教员与考试员：按航线教员、型别教员、本场教员和考试员查看进入与保持条件。
- 资质总表：按一般运行、特殊运行、训练实施和胜任力类别查看各项资质的获取和保持条件。
- 重新获得资格训练：按失效原因查看近期经历、复训/熟练检查、重获资格实践考试、机长年度航线检查、120天100小时和教员资格的完整恢复流程。
- 关键数字：按适用对象查看 90天3次起飞着陆、120天100小时、25小时经历等数字的起算事件和办理环节。

页面顶部搜索框可以搜索等级、资质、条件、训练课时和时间数字。每条记录底部的小号来源注明对应手册和章节；页面内容用于快速查询，涉及实际审批、执照签注、聘任或系统发布时仍应核对现行手册和记录。
