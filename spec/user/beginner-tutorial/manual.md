# 菜鸟教程用户手册

菜鸟教程用于查询南货航飞行人员转机型、技术等级、教员考试员、运行资质以及失去资格后的恢复办法。

从工具首页进入后，可以选择以下内容：

- 副驾驶转机型：从进入条件、理论和模拟机训练、本场训练，看到A1监视运行经历和A2检查的完整过程。
- 副驾驶技术等级：查看A1、A2、B、C、D的取得条件、运行权限，以及当前等级对应的保持、失效和恢复办法。
- 机长转机型：从D类机长进入条件，看到左座训练、运行经历、一级/二级航线检查、批准聘任和B类机长生效过程。
- 机长技术等级：查看B、C、D主线和Z、R、S特殊状态。
- 教员与考试员：查看航线教员、型别教员和考试员的训练、检查、聘任及权利范围。
- 特殊类别与例外：阅读不属于普通晋升链的身份和手册留空项。
- 资质总表：按一般运行、特殊运行、训练实施等类别查询资质的取得和保持条件。
- 重新获得资格训练：按近期经历不足、复训或熟练检查逾期、检查不合格、年度航线检查、120天100小时不足和教员资格失效等原因查看完整处理分支。
- 关键数字：核对90天3次起飞着陆和18分钟人工飞行、120天100小时、转机型25小时等数字的适用环节。

点击等级或资质条目可以展开完整内容。收起时显示加号，展开时显示减号。等级条目内已经就地列出相关恢复规则；“查看完整条目”和“关联内容”可以跳到对应的详细恢复流程或成长路径。

页面顶部搜索框可以搜索等级、资质、检查名称、训练课时和时间数字。每条记录底部注明手册来源。页面适合快速理解和定位，实际办理执照签注、聘任、资质发布或排班入库时仍须核对现行手册和个人记录。
