# 菜鸟教程用户手册

菜鸟教程用于查询南货航飞行人员转机型、技术等级、教员考试员、运行资质以及失去资格后的恢复办法。

从工具首页进入后，可以选择以下内容：

- 同型别转入：分别查看临时转入人员的训练、熟练检查和新职位运行经历要求，以及非临时同型别转入人员申请缩减复训、完成新雇员训练和半年复训、恢复符合条件的B777运行资质及失去资格后的训练要求。
- 副驾驶转机型：从进入条件、理论和模拟机训练、本场训练，看到A1监视运行经历和A2检查的完整过程。
- 副驾驶技术等级：查看A1、A2、B、C、D的取得条件、运行权限，以及当前等级对应的保持、失效和恢复办法。
- 机长转机型：从D类机长进入条件，看到左座训练、运行经历、一级/二级航线检查、批准聘任和B类机长生效过程。
- 机长技术等级：查看B、C、D主线和Z、R、S特殊状态。
- 教员与考试员：查看航线教员、型别教员和考试员的训练、检查、聘任及权利范围。
- 特殊类别与例外：阅读不属于普通晋升链的身份、资深副驾驶替代通道和手册留空项。
- 资质总表：按一般运行、特殊运行、训练实施等类别查询资质的取得和保持条件。
- 重新获得资格训练：按近期经历不足、航线飞行间断超过6个月、复训或熟练检查逾期、检查不合格、年度航线检查、120天100小时不足和教员资格失效等原因查看完整处理分支。
- 关键数字：核对90天3次起飞着陆和18分钟人工飞行、120天100小时、转机型25小时等数字的适用环节。

教程会把容易混淆的字段分开显示：航段、飞行次数、起落、人工飞行时间、PF/PM以及昼间/夜间不是同一个条件。转机型训练适用于曾在相同组类不同型别飞机的相同职务上经审定合格并服务过的机组成员；同型别转入按外公司飞行人员转入的附加训练要求办理。A1转A2的航线检查明确显示“作为PF、昼间、带指引ILS”的检查航段；机长转机型会分别显示右座经历、左座操作驾驶员经历、夜航航段、人工飞行航段和一级/二级检查航段。手册没有规定的昼夜或PF/PM组合不会由页面自行补写。

资质总表还包括I类ILS自动着陆、低能见运行（LVO）、RNP APCH、RVSM、UPRT、飞行作风、初阶EBT、除冰防冰和目视进近。查看进近类条目时，注意PF和PM位置要分别完成规定的进近次数，且“着陆”和“复飞”是不同结果；目视进近还会区分通用资格与特定CVFP机场程序。英语通信检查条目会显示按1分、2分、3分评分触发的重新带飞、不能通过国际航线检查或不能通过通信检查员检查等分支。

重新获得资格训练中包括新机长/新教员资质能力专项检查、飞行技术专项检查以及知识、程序应用、自动航径管理、人工控制和CRM胜任力缺陷恢复。局方或公司另行要求的资质能力专项检查会标记为部分确认，须先取得对应文件和飞行部书面实施材料，不能直接套用页面中其他专项检查的课时、航段或降级路径。训练或检查合格后仍需完成记录、审批发布、聘任和系统入库等生效步骤。

点击等级或资质条目可以展开当前对象的完整内容。收起时显示加号，展开时显示减号。条目中的“恢复规则”区域只显示与当前对象直接有关的摘要，点击规则名称进入唯一的完整恢复条目，不在多个页面重复展开同一套规则。详情页只提供“返回：原条目”按钮；点击返回或使用浏览器后退可以回到原来的等级、资质或转机型位置，不显示反向引用关系。

页面顶部搜索框可以搜索等级、资质、检查名称、训练课时和时间数字；搜索结果中的记录可继续进入权威详情。每条记录底部注明手册来源。数据加载成功后，点击“导出 Markdown”可下载`南货航飞行员成长与资质.md`；文件包含全部模块、权威记录、稳定锚点、恢复规则链接、来源索引和完整JSON附录，同一恢复规则只出现一次，不受当前搜索词或条目展开状态影响。页面适合快速理解和定位，实际办理执照签注、聘任、资质发布或排班入库时仍须核对现行手册和个人记录。
