# 工具首页用户手册

首页默认显示全部工具，每项显示名称、用途摘要、状态小字、开关和下载图标。显示“已启用”或“Beta 测试”的凸起项可以点击，并在新标签页打开工具；显示“冷却中”的灰色内凹项不能从首页点击，但固定工具地址仍可访问。

点击工具卡片右下角的下载图标会下载该工具自己的 ZIP。每个 ZIP 只包含一个工具，解压后直接打开根目录的 `index.html` 即可使用。工具页面原有的模板、Python 文件和依赖说明下载入口会保留在独立包内，不需要返回 watchdog 总目录。

顶部导航保留备忘录、API 文档、用户手册和 GitHub 入口，并提供白天/暗夜模式切换。API 文档作为独立 APP 维护，但只从顶栏进入，不出现在工具卡片列表。首页首次访问默认使用白天模式，切换后浏览器会记住选择。搜索框会按工具名称和描述筛选当前分类，“全部、重型、轻型、自动化”用于切换目录；没有匹配结果时页面会显示空状态。

工具列表第一项是“菜鸟教程”，以 Beta 测试状态提供面向南货航新员工的副驾驶、机长、教员考试员、资质和重新获得资格规则查询。

首页九宫格锁屏默认关闭。维护者可以在 `src/site-visibility.ts` 中开启，开启后连接九宫格最下面一行即可进入。

工具入口状态直接维护在 `src/tool/tools-data.ts` 对应条目的 `homepageState` 字段中，只使用“已启用”“Beta 测试”“冷却中”三种状态。当前“菜鸟教程”和“校对之王”为 Beta 测试，“珠海皇帝”和“自动点 OA 助手”为冷却中。
