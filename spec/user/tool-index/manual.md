# 工具首页用户手册

首页默认显示全部工具，每项只显示名称、用途摘要、状态小字和开关。显示“已启用”或“Beta 测试”的凸起项可以点击，并在新标签页打开工具；显示“冷却中”的灰色内凹项不能从首页点击，但固定工具地址仍可访问。

顶部导航保留技能、开发者、用户手册和 GitHub 入口，并提供白天/暗夜模式切换。首页首次访问默认使用白天模式，切换后浏览器会记住选择。搜索框会按工具名称和描述筛选当前分类，“全部、重型、轻型、自动化”用于切换目录；没有匹配结果时页面会显示空状态。

工具列表第一项是“菜鸟教程”，用于阅读运行手册、飞行人员训练大纲和飞行技术管理手册的章节地图与规则索引。

首页九宫格锁屏默认关闭。维护者可以在 `src/site-visibility.ts` 中开启，开启后连接九宫格最下面一行即可进入。

工具入口状态直接维护在 `src/tool/tools-data.ts` 对应条目的 `homepageState` 字段中，只使用“已启用”“Beta 测试”“冷却中”三种状态。当前“校对之王”为 Beta 测试，“珠海皇帝”和“自动点 OA 助手”为冷却中。
