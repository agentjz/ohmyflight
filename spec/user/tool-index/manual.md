# 工具首页用户手册

首页默认显示全部工具，每项只显示名称、用途摘要、状态小字和开关。显示“已启用”或“Beta 测试”的凸起项可以点击，并在新标签页打开工具；显示“维护中”或“已关闭”的灰色内凹项不能从首页点击，但固定工具地址仍可访问。

顶部导航保留技能、开发者、用户手册和 GitHub 入口。搜索框会按工具名称和描述筛选当前分类，“全部、重型、轻型、自动化”用于切换目录；没有匹配结果时页面会显示空状态。

首页九宫格锁屏默认关闭。维护者可以在 `src/site-visibility.ts` 中开启，开启后连接九宫格最下面一行即可进入。

工具入口状态直接维护在 `src/tool/tools-data.ts` 对应条目的 `homepageState` 字段中。当前“校对之王”为 Beta 测试，“珠海皇帝”为维护中，“自动点 OA 助手”为已关闭。
