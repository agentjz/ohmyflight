# 工具首页用户手册

首页默认只显示正常工具区，每项显示名称、用途摘要、状态小字、开关和下载图标。页面底部有一个低调的明文口令框：输入 `unlock`，再连续点击分类栏的“全部”按钮 3 次，每两次点击间隔不超过 700ms，即可显示独立隐藏区。输入口令后不需要在 700ms 内完成操作；刷新页面后恢复隐藏。该入口不是安全防护，固定工具地址仍可访问。

点击工具卡片右下角的下载图标会下载该工具自己的 ZIP。每个 ZIP 只包含一个工具，解压后直接打开根目录的 `index.html` 即可使用。工具页面原有的模板、Python 文件和依赖说明下载入口会保留在独立包内，不需要返回 watchdog 总目录。

顶部导航保留备忘录、用户手册和 GitHub 入口，并提供白天/暗夜模式切换。首页首次访问默认使用白天模式，切换后浏览器会记住选择。搜索框会按工具名称和描述筛选当前分类，“全部、重型、轻型、自动化”用于同时筛选正常区和已经解锁的隐藏区；没有匹配结果时页面会显示空状态。

隐藏区包含“菜鸟教程”“姓名匹配员工号”“人员结构统计”“锁班乞丐”“飞行经历查询（乞丐版）”“珠海皇帝”和“自动点 OA 助手”，各工具保留原分类。四个“冷却中”工具在隐藏区显示时，名称、状态和说明带下划线与删除线。

工具入口状态直接维护在 `src/tool/tools-data.ts` 对应条目的 `homepageState` 字段中，只使用“已启用”“Beta 测试”“冷却中”三种状态。当前“菜鸟教程”和“校对之王”为 Beta 测试，“锁班乞丐”“飞行经历查询（乞丐版）”“珠海皇帝”和“自动点 OA 助手”为冷却中。
