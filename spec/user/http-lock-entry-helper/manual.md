# 锁班皇帝（新）使用手册

## 启动

在下载并解压后的应用目录安装依赖：

```powershell
pip install -r requirements.txt
```

智能串行入口：

```powershell
python startsmartapp.py
```

原始串行入口：

```powershell
python startapp.py
```

程序只在本机 `127.0.0.1` 启动并自动打开工作台。智能入口只对健康疗养与飞行员公休做额度互换；原始入口完全按每行类型录入。

## 第一步：复制登录凭据

先在 Chrome 或 Edge 正常登录飞行门户，再按以下步骤操作：

1. 按 `F12`，打开 `Network` 面板。
2. 如果列表为空，在门户中刷新一次页面。
3. 在任意已登录请求上点鼠标右键，选择 `Copy`，再选择 `Copy as cURL`。
4. 回到工作台，把复制的整段内容粘贴到“cURL 或 Cookie Header”。
5. 点击“验证凭据”。

不需要从 cURL 中寻找 Cookie，也不要修改复制内容。验证成功后输入框自动清空，页面只显示 Session 有效、验证时间、动态类型数量和版本摘要。

不要使用 F12 Console 里的 `document.cookie`。IEB 的两个关键 Cookie 是 HttpOnly，控制台脚本读取不到，复制结果会缺少登录凭据。

## 第二步：准备数据

Excel 使用以下必需表头：

```text
员工号  姓名  锁班类型  开始日期  结束日期
```

每行的锁班类型和日期就是实际录入要求，页面没有整批类型选择器。锁班类型可以填写代码、`代码-名称` 或门户完整名称。

需要指定分钟时，可以增加“开始时间”和“结束时间”列，格式为 `HH:mm`。留空时 CRM 使用 `08:30-16:30`，其他类型使用 `08:59-19:59`。

按月份选择非连续日期时，再增加以下列：

```text
时间模式  月份  锁班日期  开始时间  结束时间
```

“时间模式”填写 `2` 或“按月份”，“月份”填写 `YYYY-MM`，“锁班日期”可填写多个日号。普通连续日期保持默认模式 1。

可以在 Excel 的“备注”列填写每行备注，也可以在页面填写统一备注。优先级是每行备注、统一备注、门户默认原因。备注最长 60 字符。

粘贴模式推荐直接从表格复制五列：员工号、姓名、锁班类型、开始日期、结束日期。白名单留空时处理全部有效数据；填写六位员工号后只处理白名单内记录。

## 第三步：数据健康检查

点击“数据健康检查”后，页面显示有效条数、无效条数和逐条原因。检查只是提示，不是确认门槛，也不会自动开始录入。

修改 Excel、粘贴内容、白名单或备注后，可以重新检查。点击“开始录入”时程序会重新读取当前内容，只处理有效数据并在日志中列出被跳过的无效项。

## 第四步：开始录入

点击“开始录入”后，程序按输入顺序串行执行。逐条结果显示员工号、门户姓名、输入类型、实际类型、输入日期、实际日期时间、处理状态、门户结果、尝试次数、冲突回退和备注。

日志和结果默认自动滚到最新一条。用鼠标向上滚动后会暂停自动置底，滚回底部后恢复。

点击“终止”会在当前 HTTP 请求或记录边界停止本批次。已经完成的结果仍保存在结果 Excel 中。

## 智能额度与冲突回退

智能入口只在健康疗养 `RECU_LVE` 与飞行员公休 `ALV_FD` 之间按目标年份可休天数互换。两类合计不足或额度表异常时，该记录失败，不提交部分结果。

“启用冲突旧锁班唯一解锁并重提一次”是复选框，默认不勾选。勾选后只有在全部已锁分页中恰好找到一条同员工、日期重叠的旧记录时才会解锁。解锁前证据先写入结果文件，解锁后复核状态，原请求只重提一次；再次冲突不会继续解锁其他记录。

## 结果与下一批

运行开始后即可点击“下载结果 Excel”。每个门户结果和冲突动作都会即时保存，所以中途终止时也能保留已完成证据。

一批完成或终止后，当前 Session 仍然有效。可以直接换 Excel 或粘贴下一批，再执行“数据健康检查”和“开始录入”，不需要重新启动服务。门户 Session 失效时页面会提示重新复制凭据。

结果文件保存在应用目录的 `results/<runId>/`，不会打进下载包，也不应提交到 Git。

## Agent HTTP 入口

agent 可以调用 `POST /api/start` 串联凭据验证、数据检查和开始录入。请求可以提供 `credentials`，也可以复用当前进程内已验证 Session。Excel 内容使用 Base64 字段 `excelBase64`，粘贴内容使用 `pastedText`。

`/api/start` 只复用用户已有登录态，不执行登录。调用方通过 `GET /api/status` 轮询进度，通过 `GET /api/download/result` 下载当前结果。
