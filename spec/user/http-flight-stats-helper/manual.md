# HTTP 飞行经历查询（新）用户手册

## 启动

下载独立应用并解压，在目录中运行：

```powershell
pip install -r requirements.txt
python start.py
```

程序只在本机 `127.0.0.1` 打开工作台，不启动 Playwright 或 Chromium。

## 验证登录凭据

先在 Chrome 或 Edge 正常登录飞行门户，然后：

1. 按 `F12` 打开 `Network`。
2. 如果请求列表为空，刷新一次门户页面。
3. 右键任意已登录请求，选择 `Copy`，再选择 `Copy as cURL`。
4. 把复制的整段内容粘贴到工作台，点击“验证凭据”。

不需要从 cURL 中寻找 Cookie，也不要改复制内容。IEB 的关键 Cookie 可能是 HttpOnly，Console 中的 `document.cookie` 无法完整导出，所以应使用 Copy as cURL。验证成功后凭据输入框会清空，Cookie 只保存在当前 Python 进程内存。

## 选择范围和输入

四个范围为：飞行时间+起落数、飞行经历+起落数、左座经历+起落数、全部数据。前三项可以组合；全部数据是全选快捷项。无论选择几个范围，后台对每个人只查询一次，再按选择输出字段。

Excel 表头使用：

```text
员工号  姓名  起始时间  截止时间
```

也支持旧工具已有的“开始日期/结束日期”等表头别名。粘贴模式按行使用员工号、姓名、开始日期和结束日期；只有一个日期时开始和结束使用同一天。

## 检查和查询

“数据健康检查”只显示有效和无效数量，不要求人工确认，也不会自动开始查询。点击“开始查询”时会重新读取当前输入，并用 4 个独立 HTTP worker 查询。

逐人结果按实际返回顺序追加，内容包含所选经历字段和起落总数，或全部可见字段。向上滚动日志或结果后，页面保持当前位置；滚回底部后恢复自动跟随。

“终止”会停止派发新查询，已经发出的请求在请求边界结束。登录态失效时也会停止派发并提示重新复制凭据。

## 结果和下一批

全部请求结束后，工具一次性生成“原版”和“去分钟版”两个 Excel。原版保留门户值；去分钟版只去掉飞行时间、飞行经历和左座经历中的分钟部分。查询期间下载按钮保持不可用。

一批完成后可以直接更换 Excel 或粘贴内容继续查询，当前登录态会保留到门户 Session 失效或服务关闭。结果保存在应用目录 `results/<runId>/`，不会打进下载包，也不应提交到 Git。

## Agent 接口

agent 可调用 `POST /api/start` 完成凭据验证、数据检查和开始查询。Excel 使用 `excelBase64`，粘贴输入使用 `pastedText`，范围使用 `scope`。调用方通过 `GET /api/status` 轮询，通过两个 download 接口取得原版和去分钟版。
