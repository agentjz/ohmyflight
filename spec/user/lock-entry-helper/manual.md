# 锁班皇帝用户手册

## 选择哪个 APP

- `startsmartapp.py`：启动智能串行工作台。支持全部锁班类型；健康疗养与飞行员公休会自动检查额度并在两类之间路由，还可在日期冲突时自动解锁唯一旧锁班并重提一次。
- `startapp.py`：启动原始串行工作台。按输入类型原样录入，不读取额度、不自动换类型。

两个 APP 都会向飞行门户生产系统提交非生产任务。

## 使用前准备

- 安装 Python 和 Chromium，并执行 `pip install -r requirements.txt` 安装 Playwright、colorama、openpyxl。
- 从工具页下载并解压完整应用，同时下载通用批量锁班模板。
- 准备员工号、姓名、锁班类型、开始日期和结束日期；日期使用 `YYYY-MM-DD`。
- 准备本轮员工号白名单和可选统一备注，逐条复核输入。
- 智能路由的健康疗养或飞行员公休记录不能跨自然年；普通锁班类型不受这项智能配额限制。

## 智能路由怎样工作

普通锁班类型按输入类型和日期原样录入。

输入健康疗养或飞行员公休时，APP 会读取当年两类休假的“可休天数”，并优先使用输入类型。例如一条两天公休记录只有一天公休额度，但健康疗养额度足够，APP 会生成：

1. 第一天使用飞行员公休并提交。
2. 回到录入页，第二天使用健康疗养并提交。

健康疗养不足时同理，先使用可用的健康疗养天数，再把连续尾部日期切换为飞行员公休。两类额度合计仍不足时，整条记录不会提交任何片段。

APP 还会核对页面计算的“锁班天数”。页面天数与日期范围不一致时停止当前记录，不继续提交。

`ALV-年假（公休假）` 与 `ALV_FD-飞行员公休（订座）` 是不同类型。普通年假原样录入，只有健康疗养和飞行员公休（订座）参与额度互换。

## 冲突回退怎样工作

启动时选择启用冲突自动解锁后，APP 在门户返回日期冲突时执行：

1. 回到“锁班查询”，查询当前员工的全部“已锁”记录。
2. 用员工号和冲突日期区间查找唯一重叠旧记录；找不到或同时命中多条时不解锁。
3. 把旧记录完整信息写入结果 Excel，再解锁门户中的旧整行。
4. 门户明确返回解锁成功并确认旧行不再已锁后，重新提交原锁班一次。
5. 重提仍失败时记录原因，跳过当前原始记录，继续下一条。

旧整行可能覆盖冲突日期之外的其他日期，解锁时会一起解除。APP 不把旧记录摘要写入新锁班原因；结果 Excel 的“备注”保存已解锁记录的锁班名称、锁班原因、开始日期和结束日期。

## 怎样操作

1. 运行 `python startsmartapp.py`（原始流程运行 `python startapp.py`），程序会打开本机工作台页面。
2. 选择 Excel 或粘贴输入；按需填写员工号白名单、统一备注和浏览器路径。智能工作台可勾选冲突旧锁班自动解锁并重提一次。
3. 点击“进入录入页面”。在打开的浏览器中扫码登录；自动导航失败时，按活动日志提示手动进入“运行管理 -> 非生产任务 -> 非生产任务录入”。
4. 点击“数据健康检查”，查看有效和无效条数以及活动日志。该检查只提示，不要求额外确认，也不会锁住“开始录入”。
5. 核对输入后点击“开始录入”，工作台开始按顺序向生产系统提交。处理期间不要手动切换脚本正在操作的页面。
6. 在“逐条录入结果”查看每个人或每个智能片段的输入类型、实际类型、日期、状态和门户结果；在“活动日志”查看当前阶段与异常。
7. 完成后点击“下载结果 Excel”复核结果。浏览器会继续保持登录，可以重新选择 Excel 或粘贴下一批，再点击“重新准备下一批”。
8. 只有点击“终止”或关闭工作台服务才会关闭自动化浏览器。

结果区和活动日志默认跟随最新一条。向上滚动即可暂停自动置底，滚回底部后恢复跟随。

## 怎样理解结果

- “成功”：门户结果已精确匹配当前实际片段。
- “额度不足”：两类智能额度合计少于需要天数，未执行生产提交。
- “预检失败/预检异常”：员工、姓名、限制表、年份或页面天数无法可靠确认，未执行生产提交。
- “冲突”：门户返回当前片段首次冲突；未启用回退时停止当前原始记录，已启用时继续查看同片段的“准备解锁”和最终重提行。
- “准备解锁”：已唯一定位旧记录并写入结果 Excel，下一步将执行解锁。
- “冲突回退失败”：未唯一定位、解锁未确认或回退页面异常；当前原始记录已跳过，批量继续下一条。
- “未执行”：前序片段未成功，因此该片段没有提交。
- “异常”：页面或结果读取过程没有可靠完成；先核对门户和结果文件，不要直接重跑。

结果 Excel 的“输入锁班类型/日期”是原始要求，“实际锁班类型/日期”是智能路由后的提交片段。“输入类型可休天数”和“替代类型可休天数”记录本次预检依据。发生回退时，“尝试次数、冲突回退、解锁…”列保存动作证据，成功重提行的“备注”保存旧锁班名称、原因和起止日期。

## 中断与恢复

- 结果 Excel 每个片段实时保存，输入 Excel 不会被改写。
- 如果首段成功、后段失败，原始记录已经部分完成。恢复前只整理未成功日期，不能重复提交成功片段。
- 浏览器关闭、登录失效或页面升级时停止运行，以结果 Excel 和门户实际记录为准。
- Excel/WPS 占用结果文件时先关闭文件，再继续操作；不能在无法保存结果证据的情况下提交。
- 工作台结果保存在应用目录的 `results` 中；该目录包含生产数据，不要上传、提交或对外分享。
