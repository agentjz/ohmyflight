# 技术等级运行资格查询助手（皇帝版）用户手册

## 启动

下载独立应用并解压，在目录中运行：

```powershell
pip install -r requirements.txt
python start.py
```

程序只在本机 `127.0.0.1` 打开工作台，不启动 Playwright 或门户浏览器。

## 验证 Cookie

先在 Chrome 或 Edge 正常登录飞行门户，按 `F12` 打开 `Network`。右键任意已登录请求，选择 `Copy`、`Copy as cURL`，把完整内容粘贴到工作台后点击“验证 Cookie”。也可以直接粘贴完整 Cookie Header。

验证成功后输入框会清空。Cookie 只保存在当前 Python 进程内存；关闭服务或门户 Session 失效后需要重新复制。

## 输入与查询

Excel 需要“员工号”“工号”或“员工编号”表头，“姓名”可选。粘贴模式每行写一个六位员工号和可选姓名。重复员工号只查询第一次，无效行会显示在健康检查和处理报告中。

“数据健康检查”只显示有效和无效数量，不要求人工确认，也不会自动开始查询。点击“开始查询”时会重新读取当前输入，并按人员顺序严格串行查询技术等级和运行资格。

逐人结果显示页面姓名、技术等级条数、运行资格条数和状态。向上滚动日志或结果列表后，页面保持当前位置；滚回底部后恢复自动跟随。单人失败不会终止整批。

“停止查询”不会强行打断已经发出的 HTTP 请求；当前人员返回后不再查询下一人，并保存已经取得的结果。

## 结果与下一批

- `处理报告`：先检查人员状态、姓名一致性和两类记录数量。
- `技术资料明细`：查看具体技术等级和运行资格。
- `汇总`：查看有效人数、成功、失败、输入错误和中断状态。
- 文本报告：快速查看本轮汇总。

每个人完成后结果 Excel 都会即时保存。批次完成后可以直接更换 Excel 或粘贴内容继续查询，当前 Session 会保留到门户登录失效或本地服务关闭。

## Agent 接口

agent 可调用 `POST /api/start` 一次完成 Cookie 验证、数据检查和查询。Excel 使用 `excelName` 与 `excelBase64`，粘贴输入使用 `pastedText`；通过 `GET /api/status` 轮询，通过 download 接口获取 Excel 和文本报告。
