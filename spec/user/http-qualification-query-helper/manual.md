# 飞行人员信息查询（皇帝版）用户手册

## 启动

下载独立应用并解压，在应用目录运行：

```powershell
pip install -r requirements.txt
python start.py
```

程序只在本机 `127.0.0.1` 打开工作台，不启动 Playwright 或门户浏览器。查询严格按输入顺序串行执行。

## 验证 Cookie

先在 Chrome 或 Edge 正常登录飞行门户，按 `F12` 打开 `Network`，右键已登录请求选择 `Copy`、`Copy as cURL`，把完整内容粘贴到工作台，点击“验证 Cookie”。也可以直接粘贴 Cookie Header。

验证成功后输入框会清空；Cookie 只保存在当前 Python 进程内存。服务关闭或门户 Session 失效后，需要重新复制。

## 输入与查询

Excel 需要“员工号”“工号”或“员工编码”表头，姓名可选；粘贴模式每行写六位员工号和可选姓名。重复员工号只查询第一次，无效行会显示在数据健康检查和处理报告中。

“数据健康检查”只显示有效和无效数量，不要求人工确认，也不会自动开始查询。点击“开始查询”时会重新读取当前输入，并按人员顺序严格串行查询：

- 基础信息：基本信息、教育经历、工作经历、职称信息、家庭信息。
- 技术等级。
- 运行资格。
- 训练检查记录：培训记录（自动遍历全部分页）和训练经历（一次读取全部返回）；不读取历史记录。

逐人结果显示页面姓名、基础信息/技术等级/运行资格/培训记录/训练经历五类条数和状态。向上滚动日志或结果列表后，页面保持当前位置；滚回底部后恢复自动跟随。单人失败不会终止整批。

“停止查询”不会强行打断已发出的 HTTP 请求；当前人员返回后不再查询下一人，并保存已经取得的结果。

## 结果与下一批

- `处理报告`：输入行号、员工号、输入姓名、页面姓名、身份核对、五类记录数量、状态和说明。
- `基础信息`、`技术等级`、`运行资格`、`培训记录`、`训练经历`：按模块查看明细，所有明细行带员工号和页面姓名；基础信息保留分区与记录序号，训练记录保留来源页码。
- `汇总`：查看输入来源、总数、成功、失败、输入错误和中断状态。
- 结构化 JSON：与 Excel 使用同一批数据，便于后续程序处理。
- 文本报告：快速查看本轮汇总。

每个人完成后结果 Excel 会立即保存。批次结束后可下载 Excel、JSON 和文本报告；可直接换 Excel 或粘贴内容继续下一批，当前 Session 会保留到门户登录失效或服务关闭。

## Agent 接口

Agent 可调用 `POST /api/start` 一次完成 Cookie 验证、数据检查和查询。Excel 使用 `excelName` 与 `excelBase64`，粘贴输入使用 `pastedText`；通过 `GET /api/status` 轮询，通过 download 接口获取 Excel、JSON 和文本报告。
