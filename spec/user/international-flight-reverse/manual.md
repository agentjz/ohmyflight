# 国际航班资质反推用户手册

## 操作

1. 上传航班明细表和员工信息表。航班表需有“员工号、日期、离场、到达”，员工表需有“员工号、姓名、地区、反推日期”。
2. 检查地区机场三字码。员工表包含“机场三字代码”表时会自动读取；也可以在页面文本框中编辑，每行格式为 `地区=LAX,JFK,ORD`。
3. 设置近期航班数。默认导出每个员工/地区最近 3 个去重后的航段，可改为其他正整数。
4. 根据业务口径调整离场/到达匹配、资质年限、重叠月数和目标月日期；目标月日期填 0 表示自然月末。
5. 点击“开始分析”，查看摘要、机场近期航班明细和数据问题。
6. 点击“导出 Excel”，下载包含汇总、近期明细、机场近期航班、机场配置和数据问题的复核文件；机场近期航班按每个人/机场分别取设定数量。

## 口径说明

- 反推日期当天包含在检索范围内，日期之后的航班不会命中。
- 同一航班的起飞、巡航、着陆阶段会合并为一个航段；同航班号同日的不同离场/到达路线分别保留。
- 最近航班日期只用于资质监控人工核对，不自动判定英语通信、单飞等资质是否有效。
- 建议有效期按“最近日期加年限再减重叠月数，并落到目标月指定日期”计算，最终办理仍需依据现行手册和飞行门户记录。
- 数据问题表中的无效行、重复任务和未配置地区需要回原 Excel 人工确认。
