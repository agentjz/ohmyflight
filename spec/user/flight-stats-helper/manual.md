# 飞行经历查询用户手册

## 使用前准备

下载独立应用并解压。安装 Python 3.10+、Playwright、openpyxl，然后在应用目录执行：

```text
pip install -r requirements.txt
playwright install chromium
```

## 启动和输入

运行 `python start.py`，工作台会在本机随机端口打开。

先勾选查询范围：飞行时间+起落数、飞行经历+起落数、左座经历+起落数或全部数据。前三项可以组合勾选，只保留对应经历和起落总数；全部数据是全选快捷项，保留页面全部可见字段。选择 Excel 时上传包含员工号、姓名、开始日期和结束日期的文件；选择粘贴时按行粘贴员工号、姓名和日期区间，日期使用 `YYYY/MM/DD` 或 `YYYY-MM-DD`。

点击“进入查询页面”后浏览器打开飞行门户登录页，按页面提示扫码并进入飞行经历页面，页面会沿用旧流程自动选择“按天查询”。点击“数据健康检查”查看有效和无效数据数量；检查只提示结果，不要求额外确认，也不自动开始查询。确认准备执行时点击“开始查询”。

agent 仍可调用本地 `/api/start` 全链路接口，沿用一次启动后进入页面并直接查询的原有方式。

## 查询和结果

登录完成后工具进入飞行经历页面并逐人查询。页面会显示等待扫码、运行中、进度、成功、失败和终止状态。单条失败会写入错误说明并继续后续人员。

每次运行目录会生成原版和去分钟版两个 Excel。原版保留页面当前可见字段和原值；去分钟版只处理“飞行时间”“飞行经历”“左座经历”的分钟部分。页面没有的字段不会补列。

查询过程中，工作台会在“逐人查询结果”区域追加每个人的结果。选择单项或组合范围时，结果包含对应经历字段和起落总数；选择“全部数据”时显示页面全部可见字段。结果区域默认跟随最新人员，向上滚动后会保持当前位置。查询完成后浏览器保持打开，点击“重新准备下一批”即可重新选择 Excel 或粘贴数据继续查询。只有点击“终止”才会关闭 worker 和浏览器，已保存的结果保留。

## 注意事项

- 不要在运行期间覆盖或移动输入文件。
- 页面改版、登录失败或账号权限不足时，应按工作台错误日志处理，不把空值当作成功结果。
- 工作台只监听本机地址，不提供远程访问、暂停或恢复。
