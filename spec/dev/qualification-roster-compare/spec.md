# 运行资质比对开发规格

## 输入与解析

- 浏览器本地读取人员信息 Excel 和飞行门户运行资质名册 Excel，支持 `.xls`、`.xlsx`。
- 通过表头结构定位工作表和表头行，不依赖文件名、sheet 名或固定列号。
- 人员信息表要求包含“员工号”“姓名”和四位大写资质代码表头；单元格 `1` 为机长、`2` 为副驾驶，其他非空值记为数据问题。
- 门户名册要求包含“员工号”“姓名”“资质类别”；每行代表一项资质，重复员工号+资质只计一次并记录问题。
- 员工号归一化后作为唯一匹配键；姓名不一致记录问题但不阻断按员工号匹配。

## 比对与输出

- 资质集合来自两侧输入，人员信息表头顺序优先，门户新增代码追加。
- 每项资质统计双方人数、共同人数、仅门户、仅人员信息和差异人数，并生成员工明细。
- 页面默认显示首个有差异资质的差异人员，可切换资质和状态。
- 导出结果包含“资质汇总”“差异明细”“数据问题”三个工作表，冻结首行并启用筛选。
- 所有页面和导出均消费同一个比对结果对象，不重复读取或重算源文件。
