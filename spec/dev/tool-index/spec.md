# 工具首页开发规格

工具首页统一展示公开工具入口，并通过“全部、重型、轻型、自动化”筛选工具，默认显示“全部”。

`src/tool/tools-data.ts` 是首页工具内容的唯一清单，保存名称、说明、入口、发布状态和分类。`src/site-visibility.ts` 的 `tools` 映射控制每个工具是否进入首页，开关键必须与工具 `entry` 一一对应。

工具区使用纯文字卡片，只显示工具名称和用途，不重复显示分类标签，不重复使用欢迎区图片，也不使用持续动画或装饰性流程元素。点击卡片后在新标签页打开对应工具。

搜索按工具名称、说明和分类文字筛选当前分类；分类数量只统计可见工具。没有匹配项时显示统一空状态。
