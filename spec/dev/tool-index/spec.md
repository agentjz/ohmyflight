# 工具首页开发规格

工具首页统一展示公开工具入口，并通过“全部、重型、轻型、自动化”筛选工具，默认显示“全部”。

`src/tool/tools-data.ts` 是首页工具内容的唯一清单，保存名称、说明、入口、发布状态、分类和可选的 `homepageState`。清单中的工具全部进入首页、搜索和分类计数，不维护独立白名单或隐藏过滤。

首页保留顶部导航和九宫格锁屏结构，锁屏由 `src/site-visibility.ts` 控制且默认关闭。顶栏提供白天/暗夜模式切换，首次访问默认白天模式，选择通过共享主题设置保存在浏览器本地。主内容不增加宣传 Hero，直接显示搜索、分类和工具索引。

页面使用新拟物视觉：背景与组件保持同一浅灰色，左上亮阴影和右下暗阴影形成凸起，输入区和按下态使用相反方向的内阴影；不使用渐变、粗边框、单边强调条或吉祥物。桌面工具索引每行五项，窄屏依次降为四栏、三栏、双栏和单栏。每项只显示工具名称、用途摘要、状态小字和只读开关。

`homepageState` 只有 `enabled`、`beta`、`cooling` 三种状态。未填写或为 `enabled` 时显示“已启用”；`beta` 显示暖色“Beta 测试”；两者都保持凸起并可在新标签页打开工具。`cooling` 显示“冷却中”，灰色内凹且不生成链接。该状态只作用于首页入口，工具固定 URL 和构建产物保持可访问。当前“校对之王”为 Beta 测试，“珠海皇帝”和“自动点 OA 助手”为冷却中。

搜索按工具名称、说明和分类文字筛选当前分类，结果数量随筛选更新。没有匹配项时显示统一空状态。
