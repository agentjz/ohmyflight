# 工具首页开发规格

工具首页统一展示公开工具入口，并通过“全部、重型、轻型、自动化”筛选工具，默认显示“全部”。

`src/tool/tools-data.ts` 是首页工具内容和独立应用导出的唯一清单，保存名称、说明、入口、发布状态、分类和可选的 `homepageState`。清单中的工具全部进入首页、搜索、分类计数和独立 ZIP 构建，不维护独立白名单、固定数量或隐藏过滤。

“菜鸟教程”固定为工具清单第一项，以 Beta 状态展示面向南货航新员工的技术等级、教员考试员、资质和重新获得资格知识；教程不混入用户手册页。

首页保留顶部导航和九宫格锁屏结构，锁屏由 `src/site-visibility.ts` 控制且默认关闭。顶栏提供白天/暗夜模式切换，首次访问默认白天模式，选择通过共享主题设置保存在浏览器本地。主内容不增加宣传 Hero，直接显示搜索、分类和工具索引。

页面使用全站共享的柔和野兽派视觉：浅灰页面、方角完整边框、无模糊硬阴影、低饱和多色点缀和轻量位移反馈。颜色、边框、阴影、状态和主题值由 `public/theme.css` 统一提供，首页 CSS 只维护首页布局和组件特判；不使用渐变、单边强调条或吉祥物。桌面工具索引每行五项，窄屏依次降为四栏、三栏、双栏和单栏。每项显示工具名称、用途摘要、状态小字、只读开关和 Bootstrap 风格下载图标，不显示文字导出按钮。

`homepageState` 只有 `enabled`、`beta`、`cooling` 三种状态。未填写或为 `enabled` 时显示“已启用”；`beta` 显示暖色“Beta 测试”；两者都保持凸起并可在新标签页打开工具。`cooling` 显示“冷却中”，灰色内凹且不生成链接。该状态只作用于首页入口，工具固定 URL 和构建产物保持可访问。当前“菜鸟教程”和“校对之王”为 Beta 测试，“珠海皇帝”和“自动点 OA 助手”为冷却中。

生产构建在 `dist/exports/` 中按工具 `entry` 逐项生成 ZIP，数量始终等于当前工具清单数量。每个 ZIP 根目录包含 `index.html`、独立应用脚本、离线运行时、主题和页面实际需要的库、模板、Worker、JSON、Python 文件及依赖说明；不包含其他工具、`__pycache__`、`.pyc`、source map 或仓库开发文件。导出脚本使用 IIFE，并由离线运行时承接 `file://` 下的本地 `fetch()` 和 Worker 资源，因此解压后可直接打开根 `index.html`。新增工具只需按既有规则加入工具清单和页面构建入口，导出数量随清单自动变化。

搜索按工具名称、说明和分类文字筛选当前分类，结果数量随筛选更新。没有匹配项时显示统一空状态。
