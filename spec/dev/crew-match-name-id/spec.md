# 姓名匹配员工号开发规格

## 产品边界

`crew-match-name-id` 从输入文本中按花名册姓名做包含匹配，输出员工号、姓名、分部、技术信息和技术等级，并允许为当前名单补充自由业务列后导出 Excel 或图片。它是浏览器本地工具，不做模糊姓名纠错、别名合并或同名人员判定。

## 输入契约

- 花名册支持 `.xlsx`、`.xls`，默认尝试加载 `public/tool/template/机组花名册.xlsx`，也允许用户重新选择。
- 第一行必须按表头包含 `员工号`、`姓名`、`分部`；`技术信息` 可选。表头匹配会移除空白，并接受包含关键字的表头。
- 员工号或姓名为空的数据行不进入花名册。
- 待查询文本为任意字符串；匹配按花名册中的完整姓名是否出现在文本中判断。

## 技术等级规则

技术等级从 `技术信息` 冒号后的内容中依次识别：`X类`、`飞行教员X`、末尾等级标识。字母统一转为大写，允许字母后带一至两位数字；无法识别时留空。

## 结果与导出

- 页面固定列顺序为员工号、姓名、分部、技术信息、技术等级。表头和正文使用同一张语义表格，水平、垂直居中，长文本允许换行。
- 用户可以增加任意数量的临时自定义列。每列使用稳定 id、自由列头和按员工号映射的单元格值；列头及所有单元格均由用户编辑，不套用预设业务规则。
- 自定义列支持删除、逐格输入和从任意单元格开始向下粘贴多行文本。自定义数据不写回花名册，清空当前名单时一并清除。
- 用户可勾选结果；复制员工号、复制姓名或导出时，有勾选则只处理勾选项，无勾选则处理全部。页面不提供分部、技术信息、技术等级及自定义列的单列复制入口。重新渲染自定义列不会丢失选择状态。
- Excel 与图片共享同一导出矩阵：默认导出员工号、姓名、分部、技术信息，再按添加顺序附加自定义列；只有勾选`导出技术等级`时，才在技术信息后加入技术等级。
- Excel 使用浅色样式工作表，包含居中换行、浅色表头、交替行底色、轻边框、列宽、行高和自动筛选。
- 图片标题由独立输入框提供，与自定义列头无关；标题为空时使用`人员名单`。
- 图片只包含标题和名单表格，不包含复选框、页面按钮或标题分割线。图片使用浅色表头和轻边框，按实际列数扩宽，长文本换行，不裁掉横向列。
- 花名册缺少必需表头时明确报错，不使用固定列号兜底。
