# IEB HTTP 锁班

用于在用户自行维护 IEB 登录态的前提下，以本地 Python HTTP 客户端替代浏览器逐条渲染和点击。旧版 `lock-entry-helper` 保持不动；纯 HTTP 新 APP 使用 `http-` 技术前缀，本项目对应目录名为 `http-lock-entry-helper`，页面名为“锁班皇帝（新）”。

## 当前已验证边界

- 用户正常登录门户后，可从 F12 Network 复制任意已登录请求为 cURL，再由本地服务提取 Cookie。不要声称 `document.cookie` 能导出完整凭据；`JSESSIONID` 和 `iebJSid` 是 HttpOnly。
- Playwright 浏览器关闭后，只凭上述两个 Cookie 已实际完成录入页、员工校验、规则提示、提交、查询、通过、撤销和解锁请求。运行时不需要 Playwright，也不依赖 localStorage 或 sessionStorage。
- 已捕获请求未包含 CSRF Token、`__VIEWSTATE`、动态签名或 Authorization Header。页面升级后出现新字段或 401/登录页响应时重新探测，不用旧结论掩盖变化。
- 成功提交、自定义分钟、自定义备注、按月份非连续日期、冲突响应、唯一旧记录解锁和单次重提均已通过真实会话验证。测试样例身份、记录号、Cookie 和响应原文不进入仓库。
- 外部提交、通过、撤销、解锁和否决都是状态变更。每次真实探测都以 owner 当次授权为边界；过去一次测试授权不能自动沿用。

## 必读参考

- 实现或排查门户 HTTP 客户端、请求字段、响应解析、时间模式、查询和状态动作时，完整读取 [HTTP 接口事实](references/http-api.md)。
- 新建或维护本地前后端、Excel/粘贴输入、人工分步、agent API、结果保存和冲突恢复时，完整读取 [工作台实现约束](references/workbench.md)。
- 仍需浏览器观察页面行为、录制网络或验证 DOM 时，同时使用 `flight-portal-probe`；涉及 Excel 解析时同时使用 `excel-dev`；正式修改工具时同时使用 `watchdog-dev`，涉及页面时再使用 `ui-clarity`。

## 不可丢失的产品意图

- 门户缺少符合当前使用习惯的批量录入能力。每行 Excel 或粘贴数据已经给出人员、类型、日期等要求，工作台负责批量执行；不得改成让用户为整批重新选择一个类型。
- 类型代码、名称、限制标记和日期拆分标记从当前登录会话返回的 `#lockType` 动态读取。静态表只可作为测试 fixture，不是生产真相。
- 保留旧版已验证的输入、智能额度、冲突唯一匹配、逐条结果、即时落盘、中断和 agent 入口行为。纯 HTTP 只替换门户交互层，不擅自改业务口径。
- 前端保持人工分步：验证凭据、数据健康检查、开始录入、终止分别触发。数据检查只提示有效/无效结果，不新增强制确认或强制拦截。
- 一批结束后会话继续保留，可换 Excel 或粘贴下一批；只有人工终止、服务退出或会话失效才结束。

## 凭据与证据

- Cookie/cURL 只交给监听 `127.0.0.1` 的本地后端，优先仅存内存；不写浏览器 localStorage，不回显 Cookie，不进入日志、状态 API、Excel、截图、fixture、Git 或错误堆栈。
- 结果目录和本地会话目录必须被 Git 忽略。临时探针放系统临时目录，输出先脱敏，研究结束后删除 Cookie、原始 HTML、身份响应和探针产物。
- 代码、测试、spec、manual 只使用虚构身份和脱敏响应。不得把真实姓名、员工号、操作人、部门、记录序号或本次测试日期组合写入仓库。

## 重新探测条件

出现以下任一情况，先停在只读请求并重新取得页面事实：

- 凭据验证返回登录页、重定向或权限不足。
- `#lockType`、查询表头或结果表头缺失。
- 请求出现新 Token、隐藏字段、签名或不同 Content-Type。
- 动态类型的 `class`/`id` 语义、时间控件或状态代码变化。
- 提交返回 200 但无法按当前人员、类型和日期归属结果。

不要为了继续批量而猜字段、复用相邻人员结果或吞掉门户错误。
