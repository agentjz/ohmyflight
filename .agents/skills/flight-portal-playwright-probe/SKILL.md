# 飞行门户 Playwright 探针

用于取得浏览器页面事实并稳定页面自动化。页面没有被真实读取前，不猜菜单路径、locator、frame、表头、按钮状态或提交值。

## Reference 路由

- 探测技术等级、运行资格、资料管理、合并单元格或技术资料批量查询时，完整读取 [技术资料页面事实](references/technical-materials.md)。
- 探测非生产任务录入、锁班查询、额度表、冲突、解锁或通过按钮时，完整读取 [非生产任务页面事实](references/nonproduction-task.md)。
- 涉及 Excel 输入或写回时同时使用 `excel-dev`；正式修改工具时同时使用 `watchdog-dev`，涉及工作台页面时再使用 `ui-clarity`。

## 探测顺序

1. 启动 `headless=False` 浏览器，通过用户维护的登录态或人工扫码进入门户。
2. 按真实菜单逐级进入目标页面，并以目标容器可见证明页面就绪。
3. 用 1 至 3 个 owner 授权样例读取可见文本、DOM、frame、表头、控件值和请求；查询优先只读。
4. 分清输入解析值、DOM 选中值、页面显示值、实际请求值和响应值，不能只凭截图或提示文字判断。
5. 按表头和同行业务字段定义归属，再使用 checkbox、按钮或记录 ID 执行动作；不按固定行号、序号或录制时 accessible name 猜目标。
6. 样例逐字段一致后才进入批量；每条结果及时保存，普通单人失败后继续，浏览器关闭则停止后续。
7. 结束时清理临时截图、HTML、录制和真实身份数据；保留用户要求的正式结果。

## 页面与会话边界

- 自动导航失败时保留可见浏览器，允许用户手动到达页面；不要把等待超时当成登录失败事实。
- 页面可能同时保留多个业务标签 DOM，重复 `id` 必须限定在当前可见容器内。
- 目标容器可能位于任一 frame；遍历 frame 后再判断缺失。
- 表格按表头解析，并正确展开 `rowspan`/`colspan`；空白选择列表头也要保留，避免整行字段左移。
- 一批结束后是否保留浏览器按当前 APP 契约执行；现有本地工作台通常保留会话，只有停止接口或服务退出才关闭。

## 写操作边界

录入、通过、撤销、解锁和否决都会修改门户状态。只有 owner 对当前样例和动作明确授权时才执行；一次授权不沿用到后续任务。执行前按业务字段唯一定位，执行后重新查询确认状态，不能只相信弹窗或 HTTP 200。

## 证据与隐私

- Cookie、真实姓名、员工号、记录 ID、页面原文、截图和探针结果不进入代码、测试、spec、日志或 Git。
- 仓库测试只使用虚构身份和脱敏 DOM fixture。
- 内网不可访问时，以 owner 提供的 HTML、截图、日志和现有代码为事实来源，并明确未真实验证。
