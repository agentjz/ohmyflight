# IEB 非生产任务页面事实

本文件记录 Playwright 观察到的非生产任务录入、锁班查询和状态动作 DOM。若目标是直接构造 HTTP 请求，读取 `flight-portal-http-probe` 的锁班 reference。

## 页面入口

菜单路径为“运行管理 -> 非生产任务”。录入使用“非生产任务录入”，历史记录和状态动作使用“锁班查询”。

页面可能同时保留两个标签页 DOM，`#lockType` 等重复 id 必须限定容器：

```text
#showNonproductionTaskImportPage #lockType
#showNonproductionTaskLockPage1 #lockType
```

录入页员工输入为 `#showIdshowNonproductionTaskImportPage`，隐藏员工号必须与当前员工一致。查询页员工输入为 `#showIdNonproductionTaskLock`，隐藏员工号为 `#staffnumNonproductionTaskLock`。

## 录入与额度

先输入员工号并确认隐藏员工号和姓名，再选择锁班类型。只有员工和类型就绪后，页面底部休假限制表才可作为事实读取。

额度表表头通常位于 `.hDiv table`，数据位于 `.bDiv table`。按以下字段映射，不按列号：

```text
休假类型
年份
休假天数
锁班天数
解锁天数
可休天数
```

`RECU_LVE` 与 `ALV_FD` 可按目标年份“可休天数”执行现有智能路由。额度表中的 ALV_FD 可能显示为“年假（公休假）”，不能据此改成普通 `ALV`。其他类型原样提交，不读取这两类额度。

提交结果分别读取普通结果表和冲突表，并按员工号、页面姓名、实际类型和完整起止日期时间归属当前记录。结果页的“继续录入”只返回录入表单；“通过”是独立状态动作。

## 锁班查询

查询页容器为 `#showNonproductionTaskLockPage1`，结果表位于 `#showNonproductionTaskResultPage table`。已观察到按钮：录入、撤销、通过、解锁；状态包含已锁、待审批、已撤销、已解锁、已否决。

读取表格时保留第一列空白选择表头，其他字段按表头映射。部门、锁班原因、冲突等可能被截断的单元格优先读取 `title` 完整值。

分页以 `#showLockListResultPageDiv #userPage` 和 Footer 链接为准。“共 N 条记录”是记录数，不是页数。翻页后确认当前页码变化，再读取当前页。

checkbox 的 `value` 是状态动作所需记录 ID，但只能在业务字段唯一定位目标行后，从该行 `.lockTaskListIds` 读取；checkbox 不参与身份判断。

## 冲突解锁

1. 从当前冲突响应读取员工、类型和时间区间并先保存证据。
2. 在锁班查询页筛选该员工全部“已锁”分页。
3. 只保留员工号一致、状态已锁且自然日区间与冲突区间重叠的记录，必须恰好一条。
4. 执行动作前保存旧行全部字段；结果保存失败时不解锁。
5. 在唯一同行勾选 checkbox，点击“解锁”。
6. 第一层原因弹窗中的 `#writeRemark` 可能被移到 `body`；从可见 `#remark` 向上定位 `.ui-dialog` 并点击确定。
7. 第二层结果弹窗只有明确包含“成功”时才确认继续。
8. 重新查询并确认旧行不再属于已锁，再回录入页重提原请求一次；仍冲突时停止当前记录，不解锁第二条。

解锁的是门户旧整行，不是只解除相交日期。新锁班原因沿用当前输入备注或门户默认原因，不把旧锁班摘要写入新原因。

## 通过与其他状态动作

通过动作只针对待审批记录，执行前按员工号、类型、完整日期时间和当前状态唯一定位。点击“通过”后重新查询，确认同一记录进入已锁且不再出现在待审批列表。

撤销、解锁和否决同样要求动作前唯一定位、动作后状态复查。不要把按钮点击成功或弹窗关闭当作业务完成。

## 失败证据

以下情况先保存临时截图、相关 frame HTML、可见文本、DOM 值和请求摘要，再判断失败：

- 隐藏员工号与输入不一致。
- 类型选中值、页面显示值与实际请求值不一致。
- 结果表头、列数或分页异常。
- 目标记录为零条或多条。
- 页面关闭、登录失效或菜单状态丢失。

证据必须脱敏，研究结束后删除。
