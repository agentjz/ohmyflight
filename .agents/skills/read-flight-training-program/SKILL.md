# 飞行人员训练大纲阅读

## 必读知识

- 回答前完整读取 `../../../spec/reference/flight-manuals/training-program.md`，不得只读取标题或搜索命中片段。
- 把用户提供的现行《飞行人员训练大纲》原文作为最终依据；独立参考文件只提供章节地图、课程链、规则核对路径和版本复核流程。
- 用户只提供摘要、截图或局部原文时，明确结论仅覆盖已有证据，不补推缺失课程或条件。

## 执行流程

1. 确认大纲名称、版本、修订号、生效日期、适用机型、人员阶段和用户问题。
2. 按独立参考文件的通用阅读模板和章节地图，完整核对进入条件、训练内容、课时、考试、检查、运行经历、保持恢复和记录要求。
3. 涉及运行权限、机组搭配、技术等级、聘任或资质发布时，分别核对运行手册和飞行技术管理手册，不把课程完成直接等同于权限生效。
4. 涉及新版复核时，按独立参考文件的完整复核流程执行，并使用 `compare-manuals` 建立全文差异证据。
5. 输出已确认版本、读取范围、章节/条款位置、适用对象、前提、训练链、检查结果、后续动作和仍无法确认的内容。

## 维护

- 章节地图、课程规则、数字口径和版本复核要求只维护在独立参考文件中，不在本文件复制。
- 菜鸟教程在构建时发布独立参考文件正文；维护业务知识后无需修改页面源码。
