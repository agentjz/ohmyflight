# 飞行人员训练大纲阅读

本 Skill 是给 Agent 使用的原始手册阅读与语义审计流程，不是南货航新员工教程正文。它不能要求读取或发布 APP 页面内容，也不能把本 Skill 的规则复制到页面。

## 证据要求

- 以用户提供的现行《飞行人员训练大纲》Word/PDF 为最终依据；先确认名称、版本、修订号、生效日期和适用机型。
- 使用 `docx-report` 或等效结构化读取方法完整读取段落、表格和附录；搜索命中只能定位范围，不能代替全文阅读。
- 结论必须逐条保留章节和条款位置，区分训练课程、经历、考试、检查、签注和资质发布，不把训练合格直接等同于运行权限。
- 与《飞行技术管理手册》出现交叉或不同字段时，两本手册并列核对；缺失条件标记为未确认，不用经验补写。

## 语义审计

按人员对象和事件链阅读：新雇员、 副驾驶转机型、机长转机型、教员/考试员、复训与熟练检查、重新获得资格和专项训练。对每一条规则确认适用对象、进入条件、起算事件、时长/经历字段、检查顺序、合格与不合格分支、降级/停飞后果、记录和审批动作。

“重新获得资格”必须按失效原因分开审计：近期经历不足、复训或熟练检查逾期、熟练检查不合格、机长年度航线检查逾期/不合格、训练后120天100小时未完成以及教员权利失效不能共用一个恢复结论。

## 维护 APP

维护菜鸟教程时，先阅读 `src/tool/app/beginner-tutorial/content/knowledge.json` 及关联 Markdown，再回到原始手册逐条复核。通用等级、资质和数字写入结构化记录；无法用统一字段表达的完整语义写入对应 Markdown；恢复流程在 `recovery` 独立模块中维护。

写入前做语义审计，写入后检查来源 ID、版本、章节、适用对象、状态和结果分支。不得用脚本把章节标题或搜索命中机械提取成正文。完成后运行构建、类型检查和测试。
