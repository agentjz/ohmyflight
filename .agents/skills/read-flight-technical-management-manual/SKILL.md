# 飞行技术管理手册阅读

本 Skill 只负责读取和审计用户提供的现行《飞行技术管理手册》，不维护南货航新员工可见的教程正文，也不把旧的 Spec 或抽取结果当作手册证据。

## 证据要求

- 以用户提供的现行《飞行技术管理手册》Word/PDF 为最终依据；先确认名称、版本、修订号、生效日期和适用机型。
- 使用 `docx-report` 或等效结构化读取方法读取段落、表格、附录和脚注；搜索命中只能定位范围，不能代替上下文审阅。
- 结论必须保留手册章节和条款位置，区分技术等级、运行资格、训练经历、考试检查、执照签注、资质审批发布和系统入库。
- 与《飞行人员训练大纲》出现交叉或不同字段时，两本手册并列核对；缺失条件标记为未确认，不用经验补写。

## 语义审计

按事件链阅读：新雇员、转机型、副驾驶和机长等级、教员/考试员聘任、复训与熟练检查、重新获得资格、运行资格、岗位胜任力、资质管理和档案记录。每条规则确认适用对象、进入条件、起算事件、时间单位、经历字段、检查顺序、合格与不合格分支、降级/停飞后果、记录和审批动作。

“重新获得资格”必须按失效原因分开审计：近期经历不足、复训或熟练检查逾期、熟练检查不合格、机长年度航线检查逾期或不合格、训练后120天100小时未完成以及教员权利失效不能共用一个恢复结论。

## 维护菜鸟教程

维护教程时，先阅读 `src/tool/app/beginner-tutorial/content/manifest.json`、`sources.json`、受影响的 `modules/` 文件及关联Markdown，再回到用户提供的原始手册逐条复核。通用等级、资质和数字写入结构化记录；无法用统一字段表达的完整语义写入对应Markdown；恢复流程在 `recovery` 独立模块中维护，并可由等级记录引用后在页面就地展开。

写入前做语义审计，写入后检查来源 ID、版本、章节、适用对象、状态和结果分支。不得用脚本把章节标题或搜索命中机械提取成正文。完成后运行构建、类型检查和测试。
