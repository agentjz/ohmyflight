# 飞行技术管理手册阅读

## 必读知识

- 回答前完整读取 `../../../spec/reference/flight-manuals/technical-management-manual.md`，不得只读取标题或搜索命中片段。
- 把用户提供的现行《飞行技术管理手册》原文作为最终依据；独立参考文件只提供章节地图、人员成长链、规则核对路径和版本复核流程。
- 用户只提供摘要、截图或局部原文时，明确结论仅覆盖已有证据，不补推缺失资格或审批记录。

## 执行流程

1. 确认手册名称、版本、修订号、生效日期、人员阶段、机型和用户问题。
2. 按独立参考文件的章节地图完整核对训练、经历、检查、岗位聘任、技术等级、运行资格、发布和档案闭环。
3. 涉及课程实施或具体航班运行权限时，分别核对训练大纲和运行手册，不把系统资格代码直接当作业务链已经闭合。
4. 涉及新版复核时，按独立参考文件的完整复核流程执行，并使用 `compare-manuals` 建立全文差异证据。
5. 输出已确认版本、读取范围、章节/条款位置、适用对象、前提、规则、例外、审批记录、后续动作和仍无法确认的内容。

## 维护

- 章节地图、等级规则、数字口径和版本复核要求只维护在独立参考文件中，不在本文件复制。
- 菜鸟教程在构建时发布独立参考文件正文；维护业务知识后无需修改页面源码。
